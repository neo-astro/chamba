📚 DATABASE SCHEMA
═══════════════════════════════════════════════════════════════════════════

users
  - id (PK)
  - email (UNIQUE)
  - password_hash
  - full_name
  - avatar_url, bio
  - role (client|professional)
  - created_at, updated_at

professionals
  - id (PK)
  - user_id (FK) → users
  - title, bio
  - categories (array)
  - hourly_rate, location
  - is_verified, is_available
  - created_at, updated_at

portfolio
  - id (PK)
  - professional_id (FK) → professionals
  - photo_url
  - title, description
  - created_at

reviews
  - id (PK)
  - professional_id (FK) → professionals
  - client_id (FK) → users
  - rating (1-5)
  - comment
  - created_at

messages
  - id (PK)
  - sender_id (FK) → users
  - receiver_id (FK) → users
  - content
  - read_at, created_at
